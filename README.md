# Pixel Survivor

Official Windows downloads for Pixel Survivor.

## Latest development release

[0.1.4.202611100634](https://github.com/cscoder69/pixel-survivor-release/releases/tag/v0.1.4.202611100634)

[Download the Windows ZIP](https://github.com/cscoder69/pixel-survivor-release/releases/download/v0.1.4.202611100634/PixelSurvivor-0.1.4.202611100634-Windows.zip)

Extract the entire ZIP and launch PixelSurvivor.exe. Keep PixelSurvivor.pck beside it. No installation is required.

If you already have an earlier version, the game updates itself from inside: ready updates display a **Close and reopen updated** button, the installer is verified before the game closes, and a rollback backup is kept. The game supports offline play.

This version adds 500 achievements with a pop-up and chime, an achievements screen (title menu, pause menu and the Meeting Hall), progress tracking for up to five achievements in the pause menu and at the end of every run, and retroactive unlocks from your recent run history. See the release notes for details. Human full-run balance testing remains ongoing.

Source is maintained in a separate private repository. This repository contains public downloads only.
