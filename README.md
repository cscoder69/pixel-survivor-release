# Pixel Survivor

Downloads oficiais para Windows.

[Baixar a versão mais recente](https://github.com/cscoder69/pixel-survivor-release/releases/latest)

Extraia o ZIP inteiro e abra PixelSurvivor.exe. Mantenha PixelSurvivor.pck ao lado do executável.

A partir da 0.9.1, o jogo verifica atualizações, avisa no topo da tela, baixa em segundo plano e instala ao fechar. Funciona offline quando não há conexão.

Este repositório contém apenas distribuição e apresentação pública.
